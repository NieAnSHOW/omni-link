# 笔记功能

## 概述

OmniLink 的笔记功能提供了一个轻量级的 Markdown 笔记管理系统。笔记以独立的 `.md` 文件形式存储，可以被外部工具（如 Obsidian、Typora）直接访问和编辑。

## 功能特性

### 核心功能

- **Markdown 编辑**：支持完整的 Markdown 语法，包括标题、列表、代码块、表格等
- **实时预览**：编辑时可实时查看渲染效果
- **自动保存**：内容变更后 2 秒自动保存，无需手动操作
- **搜索功能**：按标题快速搜索笔记
- **图片支持**：支持粘贴图片，自动保存到本地
- **文件系统存储**：笔记以 `.md` 文件形式存储，方便迁移和备份

### 编辑器功能

- **富文本工具栏**：快速插入加粗、斜体、链接、图片、代码块、表格等
- **代码高亮**：支持多种编程语言的语法高亮
- **图片粘贴**：直接粘贴剪贴板中的图片，自动保存并插入引用
- **表格编辑**：通过工具栏快速插入和编辑表格

## 使用方法

### 创建笔记

1. 点击左侧边栏的"笔记"菜单项，进入笔记页面
2. 点击左上角的"新建笔记"按钮
3. 系统会自动创建一个名为"未命名笔记"的新笔记
4. 在右侧编辑区修改标题和内容
5. 内容会自动保存，无需手动操作

### 编辑笔记

1. 在左侧笔记列表中点击要编辑的笔记
2. 右侧会显示笔记的详细内容
3. 点击"编辑"按钮进入编辑模式
4. 使用工具栏或 Markdown 语法编辑内容
5. 编辑完成后，内容会在 2 秒后自动保存

**工具栏功能**：
- **加粗**：选中文本后点击加粗按钮，或使用 `**文本**` 语法
- **斜体**：选中文本后点击斜体按钮，或使用 `*文本*` 语法
- **标题**：点击标题按钮选择标题级别，或使用 `#` 语法
- **列表**：点击列表按钮插入有序或无序列表
- **链接**：点击链接按钮插入链接，或使用 `[文本](URL)` 语法
- **图片**：点击图片按钮插入图片，或直接粘贴图片
- **代码块**：点击代码块按钮插入代码块，或使用 ` ``` ` 语法
- **表格**：点击表格按钮插入表格模板

**图片插入**：
- 方式 1：复制图片后，在编辑器中按 `Ctrl+V`（Windows/Linux）或 `Cmd+V`（macOS）粘贴
- 方式 2：点击工具栏的图片按钮，输入图片 URL
- 粘贴的图片会自动保存到笔记目录的 `images` 文件夹中

### 删除笔记

1. 在右侧笔记详情页面，点击"删除"按钮
2. 在弹出的确认对话框中点击"确认"
3. 笔记及其关联的图片会被永久删除

**注意**：删除操作不可恢复，请谨慎操作。

### 搜索笔记

1. 在左侧笔记列表顶部的搜索框中输入关键词
2. 列表会实时过滤，只显示标题包含关键词的笔记
3. 清空搜索框可恢复显示所有笔记

**当前限制**：搜索功能仅支持按标题搜索，暂不支持全文搜索。

## 存储位置

### 默认路径

- **笔记文件**：`~/.omnilink/notes/`
- **图片文件**：`~/.omnilink/notes/images/{笔记ID}/`
- **数据库**：`~/.omnilink/omnilink.db`（仅存储元数据）

### 自定义路径

1. 进入"设置"页面
2. 找到"笔记存储路径"配置项
3. 点击"浏览"按钮选择新路径
4. 系统会自动将所有笔记文件移动到新路径
5. 移动完成后会显示成功提示

**注意事项**：
- 路径变更时，系统会自动移动所有笔记文件和图片
- 如果移动失败，系统会自动回滚到原路径
- 请确保新路径有足够的磁盘空间和写入权限

## 文件格式

### 笔记文件命名

笔记文件使用以下命名规则：
```
note_{时间戳}_{笔记ID}.md
```

例如：`note_1713801234_1.md`

### 图片文件组织

图片文件存储在笔记目录的 `images` 子文件夹中，按笔记 ID 分组：
```
~/.omnilink/notes/
├── note_1713801234_1.md
├── note_1713801235_2.md
└── images/
    ├── 1/
    │   ├── image_1713801240.png
    │   └── image_1713801250.jpg
    └── 2/
        └── image_1713801260.png
```

### Markdown 引用格式

笔记中的图片使用相对路径引用：
```markdown
![图片描述](images/1/image_1713801240.png)
```

这种格式确保笔记文件可以被外部 Markdown 编辑器正确渲染。

## 外部工具集成

### 使用 Obsidian

1. 打开 Obsidian，选择"打开文件夹作为保险库"
2. 选择笔记存储路径（默认为 `~/.omnilink/notes/`）
3. Obsidian 会自动识别所有 `.md` 文件
4. 在 Obsidian 中编辑的内容会同步到 OmniLink

### 使用 Typora

1. 打开 Typora
2. 选择"文件" → "打开文件夹"
3. 选择笔记存储路径（默认为 `~/.omnilink/notes/`）
4. 在 Typora 中编辑的内容会同步到 OmniLink

### 使用 VS Code

1. 打开 VS Code
2. 选择"文件" → "打开文件夹"
3. 选择笔记存储路径（默认为 `~/.omnilink/notes/`）
4. 安装 Markdown 预览插件（如 Markdown All in One）
5. 在 VS Code 中编辑的内容会同步到 OmniLink

**注意事项**：
- 外部工具编辑后，需要在 OmniLink 中刷新笔记列表才能看到更新
- 如果外部工具修改了文件名，OmniLink 可能无法识别该笔记
- 建议在 OmniLink 中创建和管理笔记，仅在需要时使用外部工具编辑

## 数据一致性

### 自动校验

OmniLink 在启动时会自动检查笔记文件和数据库的一致性：

- **文件存在但数据库无记录**：提示用户是否导入该文件
- **数据库有记录但文件不存在**：标记为"文件丢失"，允许删除记录

### 手动校验

1. 进入"设置"页面
2. 点击"检查笔记完整性"按钮
3. 系统会扫描所有笔记文件并生成校验报告
4. 根据报告提示处理不一致的数据

## 常见问题

### 笔记文件丢失怎么办？

如果笔记文件意外丢失：
1. 检查笔记存储路径是否正确
2. 检查文件是否被移动或删除
3. 如果文件确实丢失，可以在 OmniLink 中删除对应的数据库记录
4. 建议定期备份笔记目录

### 如何备份笔记？

笔记以独立的 `.md` 文件形式存储，备份非常简单：
1. 复制整个笔记目录（默认为 `~/.omnilink/notes/`）
2. 将复制的文件夹保存到安全的位置（如云盘、移动硬盘）
3. 恢复时，只需将文件夹复制回原位置即可

### 如何迁移笔记到其他设备？

1. 在原设备上，复制整个笔记目录
2. 在新设备上，安装 OmniLink
3. 将复制的笔记目录放到新设备的对应位置
4. 在 OmniLink 设置中，将笔记存储路径指向该目录
5. 重启 OmniLink，系统会自动识别所有笔记

### 笔记占用空间过大怎么办？

1. 进入"设置"页面，查看笔记占用的磁盘空间
2. 删除不需要的笔记和图片
3. 考虑将笔记存储路径移动到更大的磁盘分区
4. 定期清理不再需要的图片文件

### 可以在多个设备上同时编辑同一个笔记吗？

当前版本不支持多设备实时同步。如果在多个设备上编辑同一个笔记：
- 最后保存的版本会覆盖之前的版本
- 可能导致数据丢失
- 建议在一个设备上完成编辑后，再在其他设备上打开

未来版本会支持多设备同步功能。
